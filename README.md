# 📰 Dev Times

**Dev Times** is a newspaper inspired developer portfolio built with React and Tailwind CSS, designed to showcase skills, experience and projects in a clean and modern style.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Site-4F8EF7?style=for-the-badge&logo=github&logoColor=white)](https://dev-times-iota.vercel.app/)

</div>

## Features

- Newspaper style responsive portfolio layout
- Dynamic current date in the header
- Professional introduction and profile section
- Career retrospective timeline
- Featured project showcase
- Categorized skills index
- Direct email and social media links
- Responsive styling for mobile, tablet and desktop
- Tailwind CSS v4 integration



## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- React Router DOM
- JavaScript
- HTML and CSS
- ESLint
